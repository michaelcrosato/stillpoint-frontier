This pass starts from public version 42, commit
`58badf2aa4d91c381ae331c23330d8db29ae906c`. The baseline's 449 unit tests pass.
Three independent read-only reviews covered gameplay, camera/input/UI, and
renderer/audio/resource lifetime alongside the main repository review.

schema, camera range, and simulation ring sizes are unchanged.

## Fixed findings

| Area | Finding and change | Regression evidence |
| --- | --- | --- |
| Canyon saves | Player and placement validation now share a −1,000 to 5,000 m range, preserving dry canyon ground previously rejected below −100 m. | A dry −640.57 m save round trip retains both player and bedroll; invalid heights remain rejected. |
| Crafting | A shared availability function drives controls and transactions; full output stacks receive specific feedback. | All six recipes are checked at capacity and with exactly enough room. |
| Preference isolation | Horizon changes and Reset Settings now write only preferences. | Engine tests verify no survey write before or after launch. |
| Operations tabs | Accessible tab-list/panel links and Left/Right, Home, End navigation were added. | Markup checks cover roles and focus attributes; real focus movement remains a manual check. |
| Interaction work | Candidates unable to beat the best visible target now skip terrain/collider visibility checks. | A 20-candidate fixture uses one visibility query; a blocked best target still permits the next visible one. |
| Container progression | Inventory reconciliation counted transferred material before its collection event counted it again. Notifications from one transfer now reduce together before one evidence reconciliation. | Single and mixed wood/fiber transfers credit one fiber once; full-capacity transfers remain no-ops. |
| Saved contracts | Inherited active IDs such as `constructor` survived normalization. Active IDs now require an own normalized journal entry. | Invalid IDs resolve to a real outstanding assignment or null. |
| Captured input | Dialog cleanup restored HUD button focus while pointer lock resumed, causing movement keys to be discarded. Captured play accepts button-targeted keys while protecting text entry. | Locked/unlocked button focus, text fields, and editable content are covered. |
| Map shortcuts | The map consumed Ctrl/Cmd browser commands and modified wheel gestures. These now pass through without moving the viewport or waypoint. | Handler review; actual browser shortcut behavior remains a manual check. |
| Camera stairs | A descending boom crossed suspended stair slabs because support selection used the player's height and the surface sweep only checked upward crossings. The sweep now queries each local vertical interval in both directions. | Real Field Unit stair geometry retracts the camera with a clear eye-to-camera ray; the open doorway remains unobstructed. |
| Shader startup | Three's uncancellable asynchronous shader poll could outlive material disposal or context replacement, throw from its timer, and leave initialization unresolved. Startup now uses synchronous `compile()` inside the existing awaited boundary and render-target restoration. | Direct and compositor compilation finish before yielding; failures restore the previous target and propagate. |
| Ambient audio | Hidden tabs and lost contexts can stop simulation before ambient gains are muted. Lifecycle suspension now clears their scheduled ramps and zeroes all four beds immediately. | The audio graph is silent without a following frame and normal mixing restores it. |
| Material registration | Tracking each new root reapplied policy to every prior material. New roots now initialize only newly retained materials. | An 81-root fixture drops roughness writes from 3,321 to 81; a shared material causes no rewrite, while an environment update still reaches all 81. |
| Teleport residency | New neighborhoods were allocated before departures were retired. Departures now unload first; caches refresh on failure and the manager only marks a center complete after all loads succeed. | Successful far travel stays within 81 registered chunks. A failure injected before construction leaves no stale gameplay targets and can be retried at the same center. |

Separate gameplay actions still reconcile immediately. Only related notifications
from a single container transfer are batched; batching unrelated actions can lose
events for ordered objectives.

The material result measures assignments, not FPS or GPU time. The chunk result
measures registered residency, not total bytes allocated. Startup compilation
can block the main thread while shaders warm; this deliberately removes a
background task whose lifetime cannot be safely cancelled with the installed Three API.

## Verification

Strict TypeScript, ESLint, and all 484 unit tests in 93 files pass after integration.
Enforced coverage is 94.53% statements, 86.58% branches, 96.02% functions, and
96.59% lines. These figures and thresholds apply to the explicit include list in
`vitest.config.ts`, not every repository file. Production build and rendered
Worker HTML are the final publication gates.
The authored camera checks use Three geometry raycasts without WebGL.
No browser, visual, or hardware performance tests were run for this pass.

## Known limits and next work

- One browser-local survey slot, with no cloud sync or cross-tab conflict handling.
- Save version 8 reads versions 1–8 and protects newer-version data. Save caps remain
  10,000 resource changes, 256 doors, 128 discoveries, 512 containers, and 64 placements.
- Camera range is 0–96 m; isometric uses perspective projection. Collision combines
  terrain, authored supports, and height-aware prisms rather than a full capsule solver.
- Visible vegetation moves; its shadow silhouettes remain static.
- Chunk creation is synchronous. Measure 20× travel on target hardware before choosing
  worker recipes and scheduled GPU uploads as the next optimization.
- The chunk retry regression injects failure before construction. Allocation partway
  through a factory is not yet exception-safe, and the Engine still shows a renderer
  interrupt for a streaming failure. Retryable manager state is not automatic recovery.
- Extract session/persistence orchestration from Engine behind a tested port when
  expanding save slots or launch modes. Consider floating-origin rebasing for distant travel.
- Dependency vulnerability scanning and penetration testing were not performed.

## Manual acceptance

1. Open KIT with the mouse, close it, recapture play, and move with WASD.
2. Focus the map plot; try Ctrl/Cmd+P, 0, plus/minus, and wheel. Browser commands
   should leave the map state alone; ordinary map keys and Alt+Arrow should still work.
3. On the Field Unit roof stairs, select third person and look upward while turning.
   The view should retract instead of passing underneath a tread. Check the open doorway too.
4. With wind/rain audible, hide the tab or suspend the renderer. Ambient beds should
   stop immediately and return when active play resumes.
5. At the fiber collection objective, take one fiber from a container. Progress should
   increase by one. Verify mixed-item take-all and full-capacity feedback.
6. Travel between distant settlements at 20× and compare matched frame captures.
   Check public startup, recovery, and repeated quality/view changes on the target GPU.
