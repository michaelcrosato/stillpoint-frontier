# Repository audit — 2026-09-05

## Scope and evidence

The baseline was public version 41. The audit covered runtime ownership,
gameplay, persistence, session isolation, input, cameras, dialogs, render
recovery, streamed resources, tooling, and documentation. Three independent
read-only reviews supported the main review.

Baseline: 416 unit tests, strict TypeScript, and lint passed. New regressions
cover the findings below. No dependency versions, world seed, road graph, save
schema, or simulation ring sizes changed.

## Fixed findings

| Area | Finding and fix |
| --- | --- |
| Gathering | Overflow destroyed loot and awarded false contract credit. Now the full yield must fit, or the resource and prior hits remain. |
| Save UI | Failed writes disabled Load despite a readable old survey. Availability is now separate from write status. |
| Saved loot | Inherited catalog keys produced NaN quantities. Only own item keys are accepted. |
| Rest | A timestamp could complete a 60-minute objective after one minute. Only real rest-event duration counts. |
| Camera angle | Tiny zoom-out snapped steep look angles. Pitch limits now blend near the endpoint. |
| Aim | Requested first-person mode centered the reticle too early. Render-frame presentation now owns the endpoint. |
| Key aliases | C/right Ctrl/right Shift could trigger two actions. Explicit bindings now own their keys. |
| Browser input | Uncaptured browser shortcuts and handled map events entered gameplay. Both are now excluded. |
| Dialogs | First Shift+Tab escaped heading-focused panels. Shared focus boundaries now cover settings, inventory, features, dev, map, and inspection. |
| Recovery | Focused recovery buttons suppressed the advertised shortcut. The button now handles the rebound key without browser modifiers. |
| Render fallback | GTAO/bloom failures left material, visibility, or clear state changed. State is restored before direct rendering resumes. |
| Plants | Performance bounds omitted plants revealed by higher quality. Bounds now include the full population. |
| Frame cost | Static GPU probes ran each frame. They are cached per context lifetime; frame counters come directly from renderer.info. |
| Tooling | Heavy tests contended across workers, and generated type state was tracked. Default concurrency is two; the cache is excluded. |

Renderer tests inject pass failures without a WebGL device. They do not prove
driver compatibility. Capability tests prove repeated reads perform no GL probes.
No FPS gain is claimed without hardware measurements.

## Known limits

- One browser-local survey slot; no cloud sync or cross-tab conflict handling.
- Save version 8 accepts versions 1–8 and will not overwrite newer-version data.
- Save caps: 10,000 resource changes, 256 doors, 128 discoveries, 512 containers,
  and 64 placements. Excess history is omitted. Review this before long campaigns.
- The camera has a 0–96 m perspective range. Isometric is an elevated style,
  not orthographic projection or an unlimited free camera.
- Collision uses terrain and authored supports, not a full 3D capsule solver.
- Visible vegetation moves, but its shadow silhouettes remain static.
- Chunk creation is synchronous. High-speed travel can still cause CPU spikes.
- Browser rendering, pointer lock, focus, and hardware timing need local GPU
  acceptance. Browser/visual tests were not run for this audit.
- Dependency vulnerability scanning and penetration testing were not performed.
  This audit is not a security certification.

## Refactor priorities — deferred

   and schedule GPU uploads.
2. Extract Engine session/persistence orchestration behind a tested port.
3. Reduce teleport peak residency by unloading departed chunks first. Prove
   shared ownership and failure behavior before changing load order.
4. Initialize only newly retained materials during chunk tracking once profiling
   confirms repeated registry updates are costly.
5. Add floating-origin rebasing and capsule collision when requirements justify it.

No speculative engine rewrite is included.

2. Cycle ISO → first person. Aim must remain projected during the transition.
3. Bind Camera View to C. It must not also crouch.
4. Test first Shift+Tab, both Tab boundaries, and Escape in each dialog.
5. Switch Performance → Ultra and turn near low plants. Check edge culling.
6. Gather at full capacity. The resource must remain with a notice.
7. Rest one minute on a 60-minute objective. Progress must remain partial.
8. Start a developer session, then load the survey. The survey must be intact.
